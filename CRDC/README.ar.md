# منصة مركز الاستشارات والبحوث والتطوير (CRDC) — أكاديمية السادات للعلوم الإدارية

English | العربية

## 1. نظرة عامة على المشروع

**منصة CRDC** هي نموذج رقمي متكامل (Full-Stack Operational Prototype) لمركز الاستشارات والبحوث والتطوير بأكاديمية السادات للعلوم الإدارية.

تجمع المنصة خدمات المركز البحثية، وتسجيل الباحثين، وإدارة الطلبات إدارياً، ومراجعة واعتماد إيصالات السداد في الخزينة، ولوحة مؤشرات الأداء في تطبيق ويب واحد آمن.

**تنويه هام:** هذه مبادرة تدريبية وتجريبية بدون ميزانية (Zero-Budget). لا تُخزَّن أي بيانات شخصية حقيقية للباحثين في هذا المستودع، ولا يتم إجراء أي تعديل على الموقع الرسمي للأكاديمية خلال هذه المرحلة.

## 2. الحالة الحالية للمشروع (Project Status)

- **المرحلة الحالية:** نموذج تشغيلي متكامل (تم إنجاز المراحل من Round 1 إلى Round 6 والتحقق منها آلياً عبر CI).
- **المكونات المكتملة:**
  - **قاعدة البيانات والأمان (`supabase/`):** مخطط PostgreSQL (`crdc` schema) يضم 15 جدولاً مع سياسات عزل البيانات على مستوى الصفوف (RLS)، ودوال `SECURITY DEFINER` محمية، وحارس لمنع حذف آخر مدير نشط، وسجل تدقيق غير قابل للتعديل (`crdc.audit_log`).
  - **بوابة الباحثين (`CRDC/researcher-portal/`):** التسجيل واستعادة كلمة المرور، التحقق من الرقم القومي المصري وجواز السفر للوافدين، تعديل البيانات الشخصية غير الحساسة بأمان، كتالوج الخدمات مع احتساب الرسوم آلياً بالجنيه المصري والدولار، تقديم طلبات منفصلة للرسائل والأبحاث، ورفع إيصالات السداد.
  - **لوحة تحكم الموظفين والإدارة وأمين الخزينة:** قائمة طلبات بترقيم صفحات من الخادم (`Keyset Pagination`)، توزيع المهام مع منع تضارب المصالح، قرارات النشر بالمجلات، مؤشرات إجمالية للمشاهد (`Viewer`)، وواجهة مخصصة لأمين الخزينة لمراجعة واعتماد أو رفض إيصالات السداد، و**لوحة الإحصائيات والمؤشرات (KPIs)** للمدير والمشاهد فقط: بطاقات مؤشرات، والإيراد الموثّق بالجنيه والدولار، ورسوم بيانية للخدمات والحالات ونوع الباحث، واتجاه شهري لآخر 12 شهراً، دون أي بيانات شخصية عبر الدالة `crdc.get_analytics_dashboard`.
  - **الاختبارات والتكامل المستمر (`.github/workflows/`):** اختبارات أمان قاعدة البيانات عبر `pgTAP` (أكثر من 200 اختبار)، فحص بناء الواجهة الأمامية، واختبارات المتصفح الآلية `Playwright E2E`.
- **الخطوات المتبقية:**
  - ربط المساعد الذكي (`CRDC/RAG`) ببوابة الباحثين.

## 3. التقنيات المعتمدة فعلياً (Tech Stack)

| المكون | التقنية المنفذة فعلياً |
| :--- | :--- |
| **الواجهة الأمامية (Frontend)** | React 19, TypeScript, Vite (واجهة عربية RTL متجاوبة) |
| **الخلفية وقاعدة البيانات** | Supabase (PostgreSQL, Auth, Private Storage, RLS, RPCs) |
| **الاختبارات والتكامل المستمر** | GitHub Actions, `pgTAP` (`supabase test db`), Playwright E2E |
| **المساعد الذكي (Chatbot / RAG)** | Python (`CRDC/RAG/`) |
| **إدارة الإصدارات** | Git / GitHub (نظام Pull Requests مع فحوصات CI إلزامية) |

## 5. الأدوار والصلاحيات (Roles & Security Model)

- **الباحث (`Researcher`):** ينشئ ملفه الشخصي مرة واحدة، ويعدّل بياناته غير المرتبطة بالهوية، ويقدم طلبات الرسائل والأبحاث، ويرفع إيصالات الدفع، ويتابع سجل حالات كل بند.
- **المراجع (`Reviewer`) والإحصائي (`Statistician`):** يعالجان البنود المسندة إليهما فقط ويحدثان حالات سير العمل.
- **أمين الخزينة (`Cashier`):** يراجع أوامر الدفع، ويحمّل ملفات الإيصالات المرفوعة من التخزين الخاص، ويعتمد أو يرفض الدفعات عبر دوال `RPC` مسجلة في سجل التدقيق (مع حجب الرقم القومي وجواز السفر).
- **المشاهد (`Viewer`):** يطلع على المؤشرات الإجمالية للوحة القيادة فقط دون الوصول للبيانات الشخصية للباحثين.
- **مدير النظام (`Admin`):** الإشراف التشغيلي الكامل، توزيع المهام على الموظفين، إدارة الأدوار (مع حماية ضد إزالة آخر مدير نشط)، والاطلاع للقراءة فقط على سجل التدقيق (`crdc.audit_log`).

## 6. هيكل الفريق والمسؤوليات

- **قائد الفريق (Team Leader) — باهر:** التنسيق العام للمشروع، الإشراف المعماري والأمني، مراجعة ودمج طلبات السحب (PRs)، مسارات CI/CD، والتوثيق.
- **فريق تطوير المنصة (سلمى، سمر، عمر):** بوابة الباحثين، لوحة الموظفين وأمين الخزينة، مخطط قاعدة البيانات، سياسات RLS، الدوال، والاختبارات.
- **لوحة المؤشرات والتحليلات (منة):** مؤشرات الأداء الرئيسية (KPIs)، الرسومات البيانية، وتحليل الأداء.
- **فريق المساعد الذكي (هاجر، ندى، آلاء):** إعداد قاعدة المعرفة، بناء نظام الاسترجاع (`CRDC/RAG`)، ودمج الشات بوت بالبوابة.

## 7. التشغيل المحلي والاختبارات

1. **تشغيل قاعدة البيانات المحلية وتطبيق التحديثات:**
   ```bash
   npx supabase start
   npx supabase db reset
   ```
2. **تشغيل اختبارات أمان قاعدة البيانات (`pgTAP`):**
   ```bash
   npx supabase test db
   ```
3. **تشغيل بوابة الواجهة الأمامية:**
   ```bash
   cd CRDC/researcher-portal
   npm install
   npm run dev
   ```
